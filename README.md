# Echoes of Angmar website mockup

A static, clickable mockup of the Echoes of Angmar site: home, FAQ, sign in and create account.
There is no backend; the forms validate input but send nothing.

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works as-is).
Screens are switched by the URL hash: `#home`, `#faq`, `#sign-in`, `#create-account`.

Text with a dotted underline is a detail still to be confirmed.
